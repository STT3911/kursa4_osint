# Описание и развитие NLP-части

## Текущее состояние

На данный момент в проекте уже реализовано:
- поиск по полю `bio` среди собранных Telegram-профилей;
- семантический режим поиска;
- гибридный режим ранжирования;
- учет OSINT-признаков при переупорядочивании результатов;
- отображение совпавших терминов;
- подсветка совпадений в карточке профиля;
- экспорт результатов поиска в CSV;
- графики для анализа качества датасета.

## Что входит в гибридный поиск

Гибридный режим учитывает:
- NLP-оценку релевантности профиля запросу;
- прямые совпадения терминов из запроса;
- наличие профессиональных площадок, например `GitHub`, `LinkedIn`, `Behance`;
- количество найденных внешних аккаунтов;
- локальные признаки профиля: `group_count`, `bio_length`, `has_photo`, `osint_score`, `exposure_level`.

## Что уже можно показать на защите

- запросы вида `python backend`, `designer figma`, `osint analyst`, `devops`;
- сравнение семантического и гибридного режима;
- изменение выдачи после включения OSINT-фильтров;
- объяснение, почему профиль оказался в топе;
- аналитические графики по покрытию и качеству данных;
- экспорт результатов поиска для последующего анализа.

## Что можно улучшать дальше

Следующая итерация NLP-модуля может включать:
- более устойчивую работу со смешанными русско-английскими `bio`;
- извлечение нормализованных сущностей: роль, стек, навыки, ссылки, маркеры профессии;
- уменьшение ложных совпадений по общим словам, например `developer`, `freelancer`, `team lead`;
- разметку набора запросов и релевантных профилей для оценки качества;
- отдельную метрику качества поиска до и после гибридного ранжирования;
- дополнительную визуализацию результатов для отчета и презентации.

## Практический вывод

NLP-часть проекта уже не ограничивается простым поиском похожих `bio`. Сейчас она включает семантический и гибридный режимы, объяснение релевантности, связь с OSINT-признаками и экспорт результатов, что делает ее полноценной аналитической подсистемой курсовой работы.
