# Сценарий демонстрации

## Подготовка

1. Установить зависимости:

```powershell
py -3.12 -m pip install -r requirements.txt
```

2. Создать локальный `.env` по шаблону `.env.example`, если нужно показывать live-сбор из Telegram.
3. Убедиться, что в корне проекта есть `osint_database.db` и CSV-выгрузки для демонстрации без сетевых запросов.

## Быстрый запуск

Desktop-интерфейс:

```powershell
py -3.12 app.py
```

Streamlit-интерфейс:

```powershell
streamlit run streamlit_app.py
```

## Что показать на защите

1. Главный экран приложения и статистику по базе.
2. Вкладку аналитики: количество профилей, наличие bio/username/photo, распределение цифрового следа.
3. Поиск по запросу `python backend` в семантическом или гибридном режиме.
4. Карточку профиля: Telegram-данные, группы, OSINT-балл, внешние аккаунты.
5. Проверку Sherlock/Snoop и ручной запуск Maigret как механизм обогащения username.
6. AI-классификацию профиля и объяснение найденных признаков.
7. Identity matching: score, verdict, false-positive risk и объяснение.
8. Экспорт `nlp_dataset.csv`, `nlp_dataset_enriched.csv`, `osint_report.csv` и Markdown-отчетов.
9. Запуск smoke-тестов:

```powershell
$env:PYTHONDONTWRITEBYTECODE="1"
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

## Короткая речь

Проект решает задачу локального OSINT-анализа открытых Telegram-профилей. Система собирает публичные данные, сохраняет их в SQLite, обогащает внешними аккаунтами через Sherlock/Snoop/Maigret, рассчитывает уровень цифрового следа и применяет NLP/AI для поиска и классификации. Важная часть работы - объяснимость: для OSINT-балла, профессионального класса и проверки внешнего аккаунта система показывает признаки, повлиявшие на результат.

## Частые вопросы

**Почему Sherlock/Snoop/Maigret не доказывают личность?**  
Они находят совпадения по username. Это полезный сигнал, но не доказательство. Поэтому добавлен identity matching и явный риск ложноположительного совпадения.

**Что делает AI-часть?**  
AI-часть выполняет семантический поиск, классифицирует профили по профессиональным направлениям и оценивает, насколько внешний аккаунт похож на аккаунт того же человека.

**Можно ли работать без Telegram-ключей?**  
Да, демонстрация аналитики, поиска и отчетов возможна на подготовленной локальной базе и CSV. Ключи нужны только для live-сбора новых данных.
