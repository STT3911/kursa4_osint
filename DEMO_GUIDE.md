# Сценарий демонстрации

## 1. Кибербезопасность и OSINT

1. Запустить desktop-приложение:

```powershell
.\.venv\Scripts\python.exe app.py
```

2. Показать локальную базу профилей и карточку пользователя.
3. Объяснить, что Telegram API-ключи лежат только в локальном `.env`.
4. Показать внешние аккаунты, найденные через Sherlock/Snoop/Maigret.
5. Объяснить `osint_score` и `exposure_level`.
6. Отдельно сказать, что совпадение username не доказывает личность.

## 2. Искусственный интеллект и NLP

1. Открыть веб-витрину:

```powershell
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py --server.port 8502
```

2. Показать вкладку NLP-поиска.
3. Выполнить запросы:

- `python backend`;
- `figma designer`;
- `devops`;
- `osint analyst`.

4. Открыть карточку профиля.
5. Показать same-person score для внешних аккаунтов.
6. Объяснить, что модель снижает риск ложных совпадений username.

## 3. Экспорт

Показать выгрузки:

- baseline CSV;
- enriched CSV;
- OSINT CSV;
- Markdown-отчет по профилю;
- сводный Markdown-отчет.

## Короткий текст для защиты

Проект состоит из двух частей. Первая часть относится к кибербезопасности: она собирает открытые Telegram-данные, ищет цифровой след пользователя и рассчитывает OSINT-оценку. Вторая часть относится к AI/NLP: она выполняет семантический поиск, классифицирует профили и оценивает, насколько найденный внешний аккаунт похож на аккаунт того же человека.
