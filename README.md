# OSINT Desktop

Локальное desktop-приложение для курсовой работы по сбору и анализу открытых данных из Telegram.

Система позволяет:
- собирать профили пользователей из открытых Telegram-групп через `Telethon`;
- сохранять профили, связи с группами и результаты проверок в `SQLite`;
- обогащать `username` через `Sherlock`;
- выполнять NLP-поиск по полю `bio`;
- использовать гибридное ранжирование на основе NLP-оценки и OSINT-признаков;
- просматривать карточки профилей с объяснением релевантности;
- строить графики по качеству датасета и цифровому следу;
- экспортировать датасеты, OSINT-отчеты и результаты поиска.

## Установка

```powershell
py -3.12 -m pip install -r requirements.txt
```

## Переменные окружения

```powershell
$env:TELEGRAM_API_ID="your_api_id"
$env:TELEGRAM_API_HASH="your_api_hash"
$env:TELEGRAM_SESSION="osint_session"
```

## Запуск

Графический интерфейс:

```powershell
py -3.12 app.py
```

CLI-сценарии:

```powershell
py -3.12 parser.py --group rabota_chaty1 --limit 100
py -3.12 ai_search.py
py -3.12 con_db.py
py -3.12 exp_csv.py
```

## Основные файлы

- `app.py` — основной графический интерфейс приложения;
- `telegram_service.py` — сбор данных из Telegram;
- `sherlock_integration.py` — интеграция `Sherlock` для поиска внешних аккаунтов;
- `nlp_search_engine.py` — семантический и гибридный поиск по профилям;
- `database.py` — схема базы данных, выборки, аналитика и экспорт;
- `COURSEWORK_STRUCTURE.md` — структура курсовой работы и разделение ролей;
- `NLP_IMPROVEMENT_BRIEF.md` — описание NLP-части и направлений развития;
- `THIRD_PARTY_NOTICES.md` — сведения о сторонних компонентах и лицензии.

## Возможности интерфейса

- вкладка сбора данных из Telegram;
- вкладка OSINT-анализа по профилям и группам;
- вкладка NLP-поиска с режимами `Семантический` и `Гибридный`;
- сравнение режимов поиска;
- карточка профиля с подсветкой совпавших терминов;
- аналитические графики по датасету;
- ручной запуск `Sherlock` для выбранного профиля;
- экспорт CSV и Markdown-отчетов.
