# Структура курсовой работы

## Тема проекта

Разработка локальной OSINT-системы для сбора открытых данных о пользователях из Telegram, их кросс-платформенного обогащения и интеллектуального поиска релевантных профилей по смыслу текстового описания.

## Разработчик 1: Data & Security / OSINT

По этой части реализовано:
- сбор профилей пользователей из Telegram через `Telethon`;
- обработка ограничений Telegram, включая `FloodWaitError`;
- проектирование и использование базы данных `SQLite`;
- хранение профилей, связей пользователя с группами и статусов проверок;
- экспорт базового и расширенного датасета;
- интеграция `Sherlock` через отдельный адаптер;
- расчет `osint_score` и уровня цифрового следа профиля;
- отдельная вкладка OSINT-анализа;
- ранжирование наиболее информативных профилей;
- отчеты по отдельным профилям в формате Markdown;
- общая сводка по курсовой работе.

Основные файлы:
- `telegram_service.py`
- `parser.py`
- `database.py`
- `sherlock_integration.py`
- `THIRD_PARTY_NOTICES.md`

## Разработчик 2: ML & Frontend

По этой части реализовано:
- локальный графический интерфейс приложения;
- семантический поиск по полю `bio`;
- гибридное ранжирование, объединяющее NLP-оценку, прямые совпадения терминов и OSINT-признаки;
- сравнение семантического и гибридного режимов поиска;
- фильтрация результатов по OSINT-баллу, уровню цифрового следа и наличию `username`;
- объяснение релевантности результата;
- подсветка совпавших терминов в карточке профиля;
- экспорт результатов поиска в CSV;
- аналитическая вкладка с графиками качества датасета;
- визуализация покрытия по `bio`, `username`, фото, группам и OSINT-баллам.

Основные файлы:
- `app.py`
- `nlp_search_engine.py`
- `ai_search.py`
- `NLP_IMPROVEMENT_BRIEF.md`

## Поток данных

1. Парсер получает данные из открытых Telegram-групп.
2. Профили и связи с группами сохраняются в `SQLite`.
3. При наличии `username` профиль может быть обогащен через `Sherlock`.
4. На основе собранных данных строятся базовый и расширенный датасеты.
5. NLP-модуль выполняет поиск по смыслу `bio`.
6. Гибридный режим дополнительно учитывает OSINT-признаки и совпадения терминов.
7. Интерфейс показывает результаты, карточки профилей, графики и OSINT-аналитику.

## Сценарий демонстрации

1. Запустить приложение командой `py -3.12 app.py`.
2. Открыть вкладку аналитики и показать графики по датасету.
3. Выполнить запрос, например `python backend` или `osint analyst`.
4. Сравнить режимы `Семантический` и `Гибридный`.
5. Открыть карточку профиля и показать объяснение релевантности.
6. Показать `OSINT-балл`, уровень цифрового следа и разбор факторов.
7. Перейти во вкладку OSINT-анализа и показать рейтинг профилей и статистику по группам.
8. При наличии `username` запустить ручную проверку `Sherlock`.
9. Экспортировать расширенный датасет, OSINT-отчет и результаты поиска.
10. Показать итоговую сводку по курсовой работе.
