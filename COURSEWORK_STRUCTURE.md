# Структура курсовой работы

## Тема проекта

Разработка локальной OSINT-системы для сбора открытых данных о пользователях Telegram, поиска их внешних цифровых следов и интеллектуального анализа профилей с помощью NLP/AI.

## Разработчик 1: OSINT, данные и безопасность

Реализуемые задачи:

- сбор открытых профилей из Telegram-групп через `Telethon`;
- realtime-проверка одного Telegram-профиля по `@username`, `t.me/...` или user id;
- получение имени, username, bio/about, фото и связи с группой;
- обработка ограничений Telegram, включая `FloodWaitError`;
- хранение данных в `SQLite`;
- интеграция `Sherlock` для поиска внешних аккаунтов по username;
- опциональная интеграция `Snoop` как второго username-enrichment инструмента;
- интеграция `Maigret` для ручной углубленной проверки username;
- сохранение статусов проверок: `pending`, `done`, `error`, `skipped`;
- сохранение источника найденного аккаунта: `sherlock`, `snoop` или `maigret`;
- расчет OSINT-признаков: наличие bio, username, фото, групп, внешних аккаунтов;
- расчет `osint_score` и уровня цифрового следа;
- экспорт baseline/enriched CSV, OSINT CSV и Markdown-отчетов.

Основные файлы:

- `telegram_service.py`
- `parser.py`
- `sherlock_integration.py`
- `snoop_integration.py`
- `maigret_integration.py`
- `database.py`
- `exp_csv.py`

## Разработчик 2: AI/NLP и анализ

Реализуемые задачи:

- семантический поиск по профилям через `sentence-transformers`;
- fallback на лексический поиск, если NLP-модель недоступна;
- гибридное ранжирование: `semantic_score + osint_score + matched_terms`;
- AI-классификация профилей по направлениям:
  - `backend`
  - `frontend`
  - `designer`
  - `devops`
  - `analyst_security`
  - `other`
- обучение классификатора поверх эмбеддингов;
- формирование отчета с метриками: accuracy, precision, recall, F1, confusion matrix;
- объяснение результата классификации и поиска;
- отображение AI-класса в выдаче и карточке профиля.

Основные файлы:

- `nlp_search_engine.py`
- `ai_classifier.py`
- `train_classifier.py`
- `ai_search.py`
- `NLP_IMPROVEMENT_BRIEF.md`

## Поток данных

1. Пользователь вводит Telegram-группу или отдельный профиль.
2. `Telethon` получает открытые Telegram-данные.
3. Данные сохраняются в `SQLite`.
4. При наличии username создаются задачи Sherlock и Snoop.
5. Sherlock и Snoop ищут внешние аккаунты и сохраняют найденные URL, Maigret запускается вручную для выбранного профиля.
6. База пересчитывает OSINT-признаки и `osint_score`.
7. NLP-модуль строит семантический индекс по bio и расширенным признакам.
8. AI-классификатор определяет профессиональное направление профиля.
9. Интерфейс показывает карточку профиля, объяснение, рейтинг и отчеты.

## Демонстрация

1. Запустить `py -3.12 app.py`.
2. Собрать несколько профилей из Telegram-группы.
3. Выполнить realtime-проверку одного `@username`.
4. Показать автоматическую очередь Sherlock/Snoop и ручной запуск Maigret.
5. Открыть карточку профиля с OSINT-баллом и внешними аккаунтами.
6. Выполнить NLP-запрос, например `python backend`.
7. Сравнить семантический и гибридный режимы.
8. Показать AI-классификацию и объяснение.
9. Запустить `train_classifier.py` и показать отчет с метриками.
10. Экспортировать CSV/Markdown-отчеты.

## Дополнение: Identity matching

AI/NLP-часть дополнена задачей проверки найденных внешних аккаунтов. После Sherlock/Snoop/Maigret система сравнивает Telegram-профиль и каждый найденный URL, рассчитывает `same-person score`, показывает риск ложного совпадения и объясняет признаки: сходство username, риск коллизии коротких ников, источник результата, тип сайта и пересечение с bio.

Для обучения используется файл `identity_pairs.csv`: аналитик экспортирует пары, вручную ставит `label=1` для того же человека и `label=0` для чужого аккаунта, затем запускает `train_identity_matcher.py`. Отчет с метриками сохраняется в `models/identity_matcher_report.json`.
